# MeMeMe Web Playtest

Public **compiled web playtest build** for MeMeMe Board Game.

This repository intentionally contains only browser-ready compiled files required to run the playtest. The private development repository, TypeScript source, tests, internal documentation, handoff notes, and source maps are not published here.

## Playtest

This build is provided for testing MeMeMe on desktop browsers and Steam Deck.

Deployment target: **GitHub Pages**.
